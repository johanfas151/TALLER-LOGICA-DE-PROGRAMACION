## Introducción

Cordial saludo.

Este repositorio reúne los talleres y actividades desarrollados durante el proceso de formación en lógica de programación del programa de Análisis y Desarrollo de Software (ADSO) del SENA.

Su propósito es fortalecer el pensamiento lógico, aprender a identificar y resolver problemas, comprender los fundamentos de los algoritmos y desarrollar habilidades básicas de programación mediante ejercicios prácticos y pseudocódigo.

## Taller 1 – Fundamentos de Lógica de Programación

En este taller se trabajan conceptos fundamentales de lógica de programación, reconocimiento de algoritmos y resolución de situaciones cotidianas mediante pasos ordenados.

Las actividades permiten comprender cómo plantear soluciones a diferentes problemas, organizar instrucciones y representar procesos de manera lógica.

## Taller 2 – Ejercicios de Lógica de Programación

Este taller contiene 15 ejercicios prácticos distribuidos en tres niveles de dificultad:

### Nivel Básico
Ejercicios orientados al manejo de operaciones matemáticas, cálculos, condiciones y conceptos iniciales de programación.

### Nivel Intermedio
Actividades que permiten fortalecer el uso de ciclos, acumuladores, validaciones y estructuras de control.

### Nivel Avanzado
Ejercicios enfocados en el manejo de vectores, matrices, números primos, métodos de ordenamiento y estructuras de programación más complejas.

## Objetivo del repositorio

Reunir las actividades realizadas durante el proceso de aprendizaje, documentar el desarrollo de los ejercicios y fortalecer progresivamente las habilidades necesarias para la solución de problemas mediante la lógica de programación.
